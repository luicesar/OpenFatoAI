Tudo que você precisa saber para usar o OpenFatoAI

📋

Pré-requisitos

Sistema Operacional

  • ✓ Windows 10+
  • ✓ macOS 11+
  • ✓ Ubuntu 20.04+ / Linux

Node.js

Node.js v18 ou superior. Necessário para executar o app em modo de desenvolvimento.

Espaço em disco

~500 MB para o app + ~150 MB para o modelo Whisper (baixado automaticamente na primeira transcrição)

Conexão com a internet

Necessária apenas para enviar texto/áudio ao provedor de IA ativo (Gemini, OpenAI ou Anthropic). A transcrição de fala funciona 100% offline após o download do modelo.

Permissões necessárias

  • ● Microfone (para grávar áudio e transcrever)
  • ● Captura de tela (para OCR e captura de tela inteira)
🚀

Instalação e Configuração

  1. 1 Faça o download do instalador para seu sistema operacional na página de releases.
  2. 2 Execute o instalador e siga as instruções na tela. No Linux, dê permissão de execução ao arquivo .AppImage se necessário.
  3. 3 Abra o OpenFatoAI. Um ícone aparecerá na bandeja do sistema.
  4. 4 Vá em AI Sources → Gemini e insira sua chave de API do Gemini para ativar os recursos de IA.
  5. 5 Conceda as permissões de microfone e captura de tela quando solicitado pelo sistema operacional.
⚠️

Você precisará de uma chave gratuita do Gemini (Google AI Studio) para usar as funções de IA. A transcrição de fala não requer chave.

🔧

Instalar Dependências (OCR)

No Linux, as ferramentas abaixo são necessárias para captura de tela e OCR:

sudo apt install scrot tesseract-ocr tesseract-ocr-por tesseract-ocr-eng

O modelo Whisper (~150 MB) é baixado automaticamente ao usar a aba Transcrições pela primeira vez. Nenhuma instalação manual é necessária.

No Windows, o OCR requer que o Tesseract-OCR seja instalado separadamente. Baixe o instalador em github.com/UB-Mannheim/tesseract e selecione os pacotes de idioma português e inglês durante a instalação. O app detecta automaticamente o caminho padrão de instalação.

No macOS, instale o Tesseract via Homebrew:

brew install tesseract tesseract-lang
🔒

Privacidade e Segurança

  • ✓Transcrição de fala processada 100% localmente — nenhum áudio sai do seu computador.
  • ✓OCR processado localmente pelo Tesseract — sem envio de imagens.
  • ✓Texto e áudio são enviados ao provedor de IA ativo somente quando você clica Enviar IA ou Parar Gravação.
  • ✓Sua chave de API é armazenada com criptografia nativa do SO (Electron safeStorage).
  • ✓A janela usa proteção de conteúdo e não aparece em gravações ou streams de tela.
📖

Como Usar — Passo a Passo

🏠 Home — Captura e IA

Capturar texto da tela

  1. 1.Deixe o conteúdo que deseja analisar visível na tela.
  2. 2.Clique em Capturar Tela Inteira ou Selecionar Área Tela (recomendado).
  3. 3.O texto extraído aparecerá no painel Texto Capturado.
  4. 4.Clique em ✦ Enviar IA para obter a resposta no painel direito.

Gravar áudio via IA

  1. 1.Clique em Iniciar Gravação e fale ou deixe o áudio capturar a conversa.
  2. 2.Clique em Parar Gravação — o áudio é processado e enviado ao provedor de IA ativo.
  3. 3.A resposta da IA aparecerá no painel Resposta IA.

🎙 Transcrições — Fala para texto (offline)

  1. 1.Clique em Transcrições na sidebar.
  2. 2.Clique em Iniciar. Na primeira vez, o modelo Whisper (~150 MB) será baixado automaticamente.
  3. 3.Fale normalmente — as transcrições aparecem em tempo real.
  4. 4.Clique em Parar. Os botões de revisão por IA aparecerão.
  5. 5.Use Quero Um Resumo Curto IA ou Quero Um Resumo Detalhado IA para processar a transcrição com a IA.
🔒

O áudio de transcrição não é enviado para nenhum servidor. O processamento é 100% local com o modelo Whisper.

⚙️ Configurações

  • ●Idioma: Alterna a interface entre Português (Brasil) e Inglês.
  • ●Tema: Alterna entre modo Claro e Escuro. Salvo automaticamente.
  • ●Ocultar agora: Esconde a janela imediatamente. Use também o atalho Ctrl+Shift+F9.
  • ●Modelo de IA (AI Sources): Cada provedor (Gemini, OpenAI, Anthropic) tem sua própria seleção de modelo — escolha conforme velocidade vs. precisão desejada.
